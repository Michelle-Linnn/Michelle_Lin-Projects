Gemini API Key 只存在这台设备上

key 保存在你自己浏览器的本地存储里，不会上传到任何地方，这个文件里也不含 key。 换设备或清了浏览器数据要重新填。
没有 key 的话去 Google AI Studio 免费申请一个。

数据备份

数据存在这个浏览器里，跟网址绑定。换网址、换手机、清缓存都会丢；iOS Safari 超过 7 天不打开也可能被系统清掉。建议每周导出一次。

导出的是一个 .json 文件，包含档案、每天的记录、训练明细和对话。不含你的 API key（那个不该到处传）。
导入是合并：同一天的记录以文件里的为准，文件里没有的日子保持不动。所以换设备、恢复数据都安全。
更新 App 版本时，只要网址没变，数据不受影响——但更新前还是先导一份更稳妥。
