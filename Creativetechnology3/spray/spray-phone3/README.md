# Street Spray · Phone Edition

把手机当喷罐，在大屏上喷涂。手机指向哪里，就喷在哪里。

## 原理

- 手机用陀螺仪姿态（`deviceorientation`）算出指向：左右转动 = 横向，上下抬压 = 纵向。
- 按住屏幕上的大按钮 = 按下喷罐；甩一下手机 = 换下一支笔（喷头）。颜色在手机上点选。
- 手机通过 WebSocket 把数据发给笔记本上的 `server.js`，再转发给大屏页面。
- iPhone 只允许 HTTPS 页面读取运动传感器，所以服务器会自动开一个免费的 Cloudflare 临时隧道，给手机一个 HTTPS 地址。大屏上的二维码就指向它。

## 第一次准备（Mac）

```bash
# 1. 装 Node.js（已装可跳过）  https://nodejs.org
# 2. 装 cloudflared（提供 HTTPS 链接）
brew install cloudflared
# 3. 进入项目文件夹，装依赖
cd spray-phone
npm install
```

## 每次演示

1. 笔记本接上学校大屏，运行：
   ```bash
   npm start
   ```
2. 在笔记本浏览器打开 `http://localhost:3001`，拖到大屏上，按 **F** 全屏。
3. 等右下角出现二维码（约 5–10 秒），用 iPhone 相机扫码。
4. 在手机上：像拿电视遥控器一样拿手机（屏幕朝上，顶端对准大屏），瞄准大屏中央，点 **Start spraying**，允许"运动与方向"权限。
5. 按住手机下方的大按钮开始喷。

可以多台手机同时扫码，每个人有自己的光标和颜色。

## 五支笔（喷头）

| 笔 | 效果 | 颜色 |
|---|---|---|
| Neon Tag | 原版：霓虹渐变 + 喷出涂鸦文字 | 自动循环，不受选色影响 |
| Fat Cap | 粗喷头，大面积雾化，适合铺底色 | 手机选色 |
| Skinny Cap | 细喷头，线条干净，适合描边、签名 | 手机选色 |
| Splatter | 甩出的颜料团，带尖刺和飞溅，移动越快甩得越远 | 手机选色 |
| Drip Marker | 实心马克笔，边画边往下流 | 手机选色 |

- 甩手机：按顺序切换到下一支笔，大屏上光标旁会弹出笔的名字。
- 也可以直接点手机上的笔图标。
- 在 Neon Tag 模式下点一个颜色，会自动切到 Fat Cap 并用这个颜色。
- 颜色栏最右边的彩虹圆圈可以自选任意颜色。

## 手机上的按钮

| 按钮 | 作用 |
|---|---|
| Center | 重新校准：先瞄准大屏中央再点 |
| Reach | 灵敏度：Small（小幅转动就能扫满屏）/ Medium / Large（大动作，更精细） |
| Clear | 连点两次清空整面墙 |

## 大屏快捷键

`F` 全屏 · `Q` 显示/隐藏二维码 · `C` 清空 · `S` 保存 PNG · `M` 鼠标测试模式（没有手机时用鼠标按住喷；`1`–`5` 换笔，`K` 换颜色）

## 常见问题

- **二维码一直不出来**：`cloudflared` 没装，或学校网络挡住了。可以让笔记本连手机热点再试。
- **手机点 Start 没反应 / 提示被拒绝**：iPhone 设置 › Safari › 高级 › 网站数据里清一下，或检查"运动与方向访问"是否打开，然后刷新页面。
- **光标慢慢偏了**：点手机上的 Center 重新校准。陀螺仪长时间使用会有轻微漂移，属正常现象。
- **想更跟手**：`display.html` 里的 `SMOOTH` 调大（例如 0.5），越大越跟手但越抖。
- **离线/测试**：`npm run local` 只开局域网 HTTP，安卓 Chrome 和电脑可用，iPhone 读不到传感器。
- **甩一下没换笔 / 太容易误换**：`phone.html` 里 `mag > 22` 是甩动阈值，调大更难触发，调小更灵敏。
